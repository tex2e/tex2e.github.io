# リニューアル初版の確認

実装日: 2026-09-20

## 起動

リポジトリ直下で `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザーで http://127.0.0.1:8000/ を開く。ビルドや外部ライブラリーのインストールは不要。

## 実装範囲

- `index.html`: 自己紹介、三つの探究、フラクタル、代表作品、プロフィールと既存の全履歴。
- `css/profile.css`: 新しいデザイン。小画面・低い画面・動きを減らす設定に対応。
- `css/ocean.css` / `js/ocean.js`: 海の配色、六角形の人物枠、光・粒子・電子回路・流れる信号。停止操作と動きを減らす設定に対応。
- `js/profile.js`: スクロール位置に基づく粒子の変形、通信表現、図形の変形。フラクタルはWorks内の生成SVGのみ。
- `image/characters/web/`: 表示サイズに合わせた配信用画像。通常表示では `normal` と小さな `thinking` を使用。PCで人物にホバーすると、原本から生成した大きな `thinking` に切り替わる。元画像は変更していない。
- 旧スタイル・ライブラリーはファイルを保持しているが、新トップページでは読み込まない。

## 確認したこと

ローカルChromeのヘッドレス実行で確認。

- 1440pxのPC表示を目視確認。375px・390px・768pxで横はみ出しなし。
- 乱数・暗号・プロトコルの各章へスクロールすると描画状態が切り替わる。
- 木の再生成ボタンで種が更新される。
- 作品履歴へのリンクで該当一覧が開く。
- 動きを減らす設定で固定演出を解除。
- 720×500 CSS px（1440×1000画面の200%拡大に相当する表示領域）で横はみ出しなし。ブラウザーのズーム操作そのものの検証ではない。
- JavaScript無効でも見出し・四つの履歴一覧・代替表示が残る。
- JavaScript実行エラーなし。重複ID、存在しないページ内リンク、存在しないローカル画像・スクリプトなし。
- 既存の公開済み実績リンクを引き継いだ。ブログとFreepikへのHTTPリンクはHTTPSに統一。

## 初版の位置づけ

実際の見た目とスクロール感を評価するための初版。公開・コミットは行っていない。実機Safari・Firefoxの確認、最終的な文言・クレジットの確認は別途行う。

参考サイトの具体的なスクロール動作を再現したものではない。暗号・通信の図形は概念的な表現であり、特定の暗号アルゴリズムやTLSメッセージ列を表すものではない。

## 海のテーマへの更新

PC・スマートフォン幅で再確認。海面からの光、浮遊粒子、鍵の形への変形、曲線に沿う通信、大小の海底植物を追加した。人物画像は引き続きnormalとthinkingのみ。アニメーションは約30fpsを上限にし、タブ非表示時に停止。現在のフラクタルは静的SVGをWorksのみに表示する。

## フラクタルの分散配置（旧案・撤回済み）

独立したフラクタル紹介セクション・再生成ボタン・履歴内の重複紹介を除去。Recursive Tree Rendererの紹介とリンクはSelected Worksの一件に集約した。

`js/gardens.js` が冒頭、導入、三つの探究、作品、プロフィール、連絡先の8か所に計16本を生成する。シードは全て異なり、角度・枝の縮小率・傾きもシードから決まる。静的SVGなのでフレームごとの再計算はなく、画面サイズ変更や履歴開閉にもCSSで追従する。

Chromeで16種類のシードと16種類の樹形、紹介リンクがworks内のみであること、既存の暗号章の描画、375/390/768pxで横はみ出しと実行エラーがないことを確認。以前の再生成ボタンの検証記録は、削除前の実装に対するもの。

## 現在の方針：電子の海

フラクタルはSelected WorksのRecursive Tree Rendererカード内だけに限定。写真をシード2027で生成した `image/works/recursive-tree-preview.svg` に置き換えた。背景の16本はすべて除去し、`js/gardens.js` と分散配置用CSSも削除した。

`sample.png` の回路・接点・鍵・潜る視点を参照し、広くて深い電子の海を表現。背景は45度に折れる経路、その上を流れる信号、小さなビット表現を加え、自然の海の要素を抑えた。

Chromeでフラクタル画像がworks内の一件のみであること、背景の木が0件であること、画像の読み込み、信号のアニメーションと停止、375/390/768pxの横はみ出しなし、実行エラーなしを確認。

## 暗号・プロトコル中心の構成と正六角形

「これまでの制作物」「その他の制作物」と一覧へのリンクを除去。元の一覧は `docs/archived-works.html` に再掲載用として保持。冒頭・メタ情報は暗号とプロトコルを中心にし、乱数はその土台として説明する。

六角形は頂点を外接枠の左右端に置き、枠の幅/高さをsqrt(3)/2に統一。人物枠・プロフィール・解説アイコン・背景・ロゴが対象。人物下部の透明グラデーションは維持。PC・390px・768pxで実表示の比率と横はみ出しなしを確認。ページ内リンクの行き先も確認済み。

## Worksの動きと枝先の拡大

フラクタルSVGの表示範囲を樹冠に絞り、カード全体で細かな枝分かれを見せる構図に変更。ホバー・キーボードフォーカスでさらに拡大する。RFCは原文・対訳の紙が開き、連載は二つのタイトルが左右へ動き、TLSは信号が経路を流れる。スクロール時にはパネル内の図形だけが小さく移動する。

`js/works.js` はスクロール時に表示状態と位置を更新する。TLSのアニメーションは画面外・非表示タブで停止。既存の停止ボタンとOSの動きを減らす設定にも対応。ホバーズーム、スクロール変化、TLSの動き、動きを減らす設定、375/390/768px幅の横はみ出しなしをChromeで確認。

## 冒頭のジェネラティブアート：暗号の海（2026-09-21）

回路背景を、対数的に深淵へ収束する波面と格子に変更。Canvas 2Dで波の変形、ミントと金色の光の流れ、奥へ進む粒子、浮遊する微粒子を生成する。マウス移動は小さな視差、スクロールは深海への減光として反映。乱数・耐量子暗号・ゼロ知識証明・鍵交換のラベルは分野の広がりを示すもので、アルゴリズムの正確な可視化ではない。

見出しは「暗号の海は、どこまでも深い。」へ変更。人物は右下の小さな紹介として残し、波面と文字を主役にした。スマートフォンでは本文の下に深淵が見える構図に変更。外部依存なし。約30fpsを上限とし、モバイルでは格子密度を減らす。停止・再開、OSの動きを減らす設定、タブ非表示時の停止に対応。Chromeのメディア設定変更イベントが遅れる場合も描画フレームで停止状態を同期する。

ローカルのヘッドレスChromeで確認：
- 375×667、390×844、768×1024、720×500、1440×900で横はみ出しなし。リンクと人物の表示領域の重なりなし。
- アニメーション、停止中のマウス移動でも静止、再開、OSの動きを減らす設定による静止と操作ボタンの非表示。
- 1440px幅で描画イベント間隔は平均約34ms（検証環境の値。実機性能を保証するものではない）。
- JavaScript無効でも見出しを表示。JavaScript実行エラーなし、構文確認・差分の空白確認に問題なし。
- PC・390pxのスクリーンショットを目視確認。実機モバイル・Safari・Firefoxは未検証。

## 三つの世界をつなぐ進化の樹（2026-09-21）

三つの探究にあった粒子・鍵・通信の小さな切り替え表示を、全幅の連続したジェネラティブアートへ置き換えた。「ひとつの源流から、無数の世界へ。」の導入に続き、スクロールで縦につながる三つの世界をたどる。

- 乱数：ミント色の有機的な枝と胞子。ENTROPY、TRNG、CSPRNG、DRBG、SEED、SAMPLING。
- 暗号技術：金色の直線的な分岐と結晶。HASH、SYMMETRIC KEY、PUBLIC KEY、POST-QUANTUM、ZERO-KNOWLEDGE、SIGNATURE。
- プロトコル：青い神経網状の枝と横方向の接続。TLS 1.3、SSH、QUIC、IPsec、KEY EXCHANGE、AUTHENTICATION。

三世界は同じ座標空間にあり、すべての主枝が共通の幹から分岐する。光は幹と枝を流れる。これは技術の関連を表す架空の生態系で、厳密な分類・依存関係・歴史的な系統図ではない。以前の「背景のフラクタルは置かない」という構成は今回の要望で更新した。Worksの作品カードは維持。

`js/profile.js` は枝をシード付きで生成し、静的な形を別Canvasにキャッシュする。画面上ではその一部分と動く光だけを描画する。画面外ではアートの再描画を止め、既存のoceanframeと停止状態を共有する。世界内にも停止・再開ボタンを設けた。スマートフォンでは説明文を上、枝を下に配置。JS無効時も説明とCSSによる幹の代替表示が残る。

検証：ローカルChromeでPCの三世界と390px幅を目視確認。375×667、390×844、768×1024、720×500、1440×900の各三世界で横はみ出しなし、停止ボタンが画面内にあることを確認。ボタンの実クリック、停止中の静止とスクロールでの次世界表示、再開、OSの動きを減らす設定、履歴アンカー、JS無効時の三章表示を確認。実行エラーなし。Safari・Firefox・実機モバイルは未検証。

### 幹と枝の揺らぎ（撤回済み）

三世界を通じて連続する二つの低速の波を加え、幹・枝・技術名が水中を漂うように変形する。静的な描画を細い帯に分けて横方向へずらし、枝を毎フレーム生成し直さない。幹と枝を流れる光にも同じ変形を適用し、経路から外れないようにした。PCの最大振幅は24px、スマートフォンは画面幅に合わせて縮小する。停止時は揺れも固定される。

Chromeで幹の位置が時間とともに変わること、停止・再開、OSの動きを減らす設定、および5画面サイズ・全三世界の表示を再確認。実行エラーなし。

### 作品説明文の表示修正

進化の樹の固定Canvasが次のWorksセクションへ重なり、最初の二枚の説明文を覆っていた。負のマージンによる重ね合わせをCSS Gridの同一セル配置へ変更し、固定表示が探究セクション内で終了するよう修正。説明文はコミット7f24e3cと同じ内容を維持。390・768・1440px幅で、連載とRFC Transの説明文を覆う要素がなく、CanvasがWorksへはみ出さないことを確認。

### 揺らぎの撤回（2026-09-22）

CPU使用量への要望を受け、帯ごとに背景を変形する処理を除去。キャッシュした静的な背景を一度のdrawImageで描画し、幹と枝を固定した以前の状態に戻した。光が流れる動き、停止・再開、スクロールで三世界を巡る構成、作品説明文への重なり修正は維持。
